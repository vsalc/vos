# vos

The vocabulary of the vos project: how the work is divided and how learning is checked. Kernel terms are added here as each one is learned and settled.

## Language

### Work

**Milestone**:
One of the eight stages of the kernel. Each ends with something that boots and visibly works.
_Avoid_: Phase, stage, sprint

**To-do**:
One bite-sized piece of a milestone, small enough to be a single pull request.
_Avoid_: Task, ticket, issue

**Reference kernel**:
An existing kernel read to see how someone else solved a problem. xv6 is the main one. Never a source of code.
_Avoid_: Base, template, starter

### Learning

**Handoff**:
A written brief that carries a topic between a coding session and a voice session, in either direction.
_Avoid_: Summary, notes, prompt

**Quiz**:
Questions Victor answers before implementing a to-do, to confirm he understands it.
_Avoid_: Test, check, exam

**Security lens**:
A short note written by Victor at the end of a milestone: the control the milestone implements and how that control gets attacked.
_Avoid_: Threat model, security review
